# AI-Productivity-Assistant
AI assistant to automate workplace tasks

## Problem Statement
Professionals across industries spend significant time on repetitive tasks such as drafting emails, summarizing meeting notes, and planning schedules. This project aims to solve this challenge by creating an AI-powered assistant that simplifies and automates these processes, saving time and improving productivity.

## Features
- Smart Email Generator (tone + audience-based)
- Meeting Notes Summarizer (key points, actions, deadlines)
- AI Task Planner (prioritization + scheduling)

## Tools Used
- ChatGPT API
- Lovable.dev (for building the web app UI)
- GitHub (for version control and documentation)

## Disclaimer
AI-generated content may require human review.


## User Workflow
1. **Input**
   - User provides context (e.g., meeting notes, email details, task list).

2. **AI Processing**
   - Assistant uses structured prompts to generate outputs.
   - Example: "Write a professional email to [audience] with a [tone]. Context: [details]."

3. **Output**
   - Assistant returns clear, professional results:
     - Drafted email
     - Concise meeting summary
     - Prioritized task plan

---

## Feature Workflows
- **Smart Email Generator**
  - Input: Recipient + tone + context
  - AI: Generates draft email
  - Output: Polished email ready to send

- **Meeting Notes Summarizer**
  - Input: Raw meeting notes
  - AI: Extracts key points, decisions, deadlines
  - Output: Concise summary with action items

- **AI Task Planner**
  - Input: List of tasks
  - AI: Prioritizes by urgency/importance
  - Output: Structured daily/weekly plan
