# AI-Productivity-Assistant
AI assistant to automate workplace tasks

## Problem Statement
Professionals across industries spend significant time on repetitive tasks such as drafting emails, summarizing meeting notes, and planning schedules. This project aims to solve this challenge by creating an AI-powered assistant that simplifies and automates these processes, saving time and improving productivity.

## Features
- Smart Email Generator (tone + audience-based)
- Meeting Notes Summarizer (key points, actions, deadlines)
- AI Task Planner (prioritization + scheduling)

## Tools Used
- ChatGPT API
- Lovable.dev (for building the web app UI)
- GitHub (for version control and documentation)

## Disclaimer
AI-generated content may require human review.
